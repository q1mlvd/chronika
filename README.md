# 📊 Хроніка — щоденник продуктивності

Особистий щоденник справ і фінансів: щодня записуєш, що зробив, скільки заробив і витратив, а сайт збирає **звіти за тиждень і місяць** з графіками, порівнянням з минулим періодом і автоматичними висновками.

**Демо:** https://q1mlvd.github.io/chronika/

## Можливості

- ✍️ **Швидкий запис дня**: текст, категорія, витрачений час, позначка «перемога», `Ctrl+Enter` для збереження
- 😀 **Настрій і нотатка** до кожного дня, автозбереження
- 🔥 **Серія днів поспіль** з конфеті на рубежах 3/7/14/30/100 днів
- 🟩 **Теплова карта активності за рік** у стилі GitHub, клік по дню відкриває його
- 💰 **Гроші**: доходи й витрати за категоріями, залишок, середні витрати на день, найбільші покупки; валюта за замовчуванням ₴
- 📊 **Звіт за тиждень або місяць** за кнопкою:
  - 6 KPI з динамікою до минулого періоду (справи, час, активні дні, настрій, перемоги, найкраща серія)
  - SVG-графік по днях з настроєм
  - розподіл за категоріями
  - фінансовий блок: заробив, витратив, залишок, витрати за категоріями
  - автоматичні висновки: найкращий день, головна категорія, зв'язок настрою й продуктивності, куди пішли гроші
  - повний список справ по днях
  - експорт: копіювання, `.md`, PDF/друк
- 🤖 **Автоматика**: на початку тижня або місяця сайт сам пропонує готовий звіт за минулий період, вечірнє нагадування, якщо день порожній
- 🔎 **Історія** з пошуком (підсвічування збігів), фільтром за категорією й перемогами, редагуванням і видаленням зі скасуванням
- ☁️ **Хмарна синхронізація через Supabase** (вхід за посиланням на email, без пароля) або повністю локальний режим
- 📱 **PWA**: встановлюється на телефон як застосунок і працює офлайн
- 🌗 Темна і світла теми, адаптивна верстка, гарячі клавіші `N` (новий запис), `M` (гроші), `R` (звіт)
- 💾 Експорт та імпорт JSON-бекапу, демо-дані одним кліком

## Стек

Чистий HTML/CSS/JavaScript (ES-модулі), без збірки й фреймворків. Графіки намальовані вручну на SVG. Бекенд — Supabase (Postgres + Auth + Row Level Security). Хостинг — GitHub Pages.

## Підключення хмари

1. Створи безкоштовний проєкт на [supabase.com](https://supabase.com).
2. У **SQL Editor** виконай [`supabase/schema.sql`](supabase/schema.sql).
3. У **Authentication → URL Configuration** додай адресу сайту в Site URL і Redirect URLs.
4. Скопіюй `Project URL` і `anon`/`publishable` ключ з **Project Settings → API** у [`config.js`](config.js) або встав їх на сайті: **Налаштування → Хмара**.

Публічний ключ можна зберігати в коді: доступ до даних обмежують політики RLS, і кожен користувач бачить лише свої записи.
