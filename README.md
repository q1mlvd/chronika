# 📊 Хроника — дневник продуктивности

Личный дневник дел: каждый день записываешь, что сделал, а сайт собирает **отчёты за неделю и месяц** с графиками, сравнением с прошлым периодом и автоматическими выводами.

**Демо:** https://q1mlvd.github.io/chronika/

## Возможности

- ✍️ **Быстрая запись дня**: текст, категория, затраченное время, отметка «победа», `Ctrl+Enter` для сохранения
- 😀 **Настроение и заметка** к каждому дню, автосохранение
- 🔥 **Серия дней подряд** с конфетти на рубежах 3/7/14/30/100 дней
- 🟩 **Тепловая карта активности за год** в стиле GitHub, клик по дню открывает его
- 📊 **Отчёт за неделю или месяц** по кнопке:
  - 6 KPI с динамикой к прошлому периоду (дела, время, активные дни, настроение, победы, лучшая серия)
  - SVG-график по дням с настроением
  - распределение по категориям
  - автоматические выводы: лучший день, главная категория, связь настроения и продуктивности
  - полный список дел по дням
  - экспорт: копирование, `.md`, PDF/печать
- 🤖 **Автоматика**: в начале недели или месяца сайт сам предлагает готовый отчёт за прошедший период, вечернее напоминание, если день пустой
- 🔎 **История** с поиском (подсветка совпадений), фильтром по категории и победам, редактированием и удалением с отменой
- ☁️ **Облачная синхронизация через Supabase** (вход по ссылке на email, без пароля) или полностью локальный режим
- 📱 **PWA**: ставится на телефон как приложение и работает офлайн
- 🌗 Тёмная и светлая темы, адаптивная вёрстка, горячие клавиши `N` (новая запись) и `R` (отчёт)
- 💾 Экспорт и импорт JSON-бэкапа, демо-данные одним кликом

## Стек

Чистый HTML/CSS/JavaScript (ES-модули), без сборки и фреймворков. Графики нарисованы вручную на SVG. Бэкенд — Supabase (Postgres + Auth + Row Level Security). Хостинг — GitHub Pages.

## Подключение облака

1. Создай бесплатный проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполни [`supabase/schema.sql`](supabase/schema.sql).
3. В **Authentication → URL Configuration** добавь адрес сайта в Site URL и Redirect URLs.
4. Скопируй `Project URL` и `anon`/`publishable` ключ из **Project Settings → API** в [`config.js`](config.js) или вставь их на сайте: **Настройки → Облако**.

Публичный ключ можно хранить в коде: доступ к данным ограничивают политики RLS, и каждый пользователь видит только свои записи.

## Локальный запуск
